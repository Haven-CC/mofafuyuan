# 魔方复原工具

一个基于网页的魔方复原和学习工具。

线上访问地址：

https://mofafuyuan.vercel.app

GitHub 仓库：

https://github.com/Haven-CC/mofafuyuan

## 项目简介

这个工具主要用来帮助用户把现实中的 3x3 魔方录入到网页里，然后生成一步一步的复原步骤。

用户可以按 6 个面的颜色录入魔方状态，网页会显示对应的 3D 魔方，并提供可点击的复原步骤。每点击一次“下一步”，3D 魔方会执行一步动作，用户可以照着现实魔方同步操作。

项目也加入了基础教学内容，帮助新手理解魔方转法和复原思路。

## 当前功能

- 3x3 魔方现实状态录入
- 3x3 自动生成复原步骤
- 3D 魔方可拖拽观察
- 下一步、上一步、自动播放、回到录入状态
- 颜色数量和中心块校验
- 魔方基础转法说明
- 新手复原法教学
- 4x4 示例打乱和示例复原动画

## 重要说明

3x3 模式支持根据用户录入的现实魔方状态自动求解。

4x4 模式目前支持网页内“示例打乱”的真实转动复原，用于演示 4 阶魔方的转动效果。现实 4x4 任意状态自动求解还需要接入专门的 4x4 求解器，当前版本暂未支持。

## 技术栈

- Vite
- TypeScript
- Three.js
- cubejs

## 本地运行

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

默认访问：

```bash
http://127.0.0.1:5173
```

构建生产版本：

```bash
npm run build
```

本地预览生产版本：

```bash
npm run preview
```
